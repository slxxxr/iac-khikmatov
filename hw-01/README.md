# Стенд для показов (ДЗ 1)

Стенд для демонстрации продукта клиентам. Поднимается перед показом и удаляется после него, между показами ничего не стоит.

## Состав

- сеть `khikmatov-02-net`, подсети в `ru-central1-b` (10.12.1.0/24) и `ru-central1-d` (10.12.2.0/24);
- 3 веб-сервера `khikmatov-02-web-N` с nginx на порту 8006, распределены по двум зонам;
- сервер приложения `khikmatov-02-app` без публичного адреса;
- NAT-шлюз `khikmatov-02-nat` и таблица маршрутизации `khikmatov-02-rt` для выхода сервера приложения в интернет;
- сетевой балансировщик `khikmatov-02-lb`: порт 80 → 8006, проверка состояния по HTTP.

## Что нужно

WSL или Linux с `bash`, настроенный `yc` (`yc init`), `jq`, `curl`, `envsubst` (пакет `gettext-base`) и ключ `~/.ssh/id_ed25519`.

## Поднять стенд

```bash
bash hw-01/create.sh
```

Повторный запуск безопасен: уже созданные ресурсы пропускаются. Скрипт завершается, когда балансировщик начинает отвечать, и печатает его адрес.

## Параметры

Аргумент важнее переменной окружения, переменная окружения важнее значения по умолчанию.

| Аргумент | Переменная | По умолчанию |
|---|---|---|
| `--prefix` | `PREFIX` | `khikmatov-02` |
| `--web-count` | `WEB_COUNT` | `3` |
| `--port` | `APP_PORT` | `8006` |
| `--greeting` | `GREETING` | `cloudlab` |

Пример:

```bash
bash hw-01/create.sh --web-count 3
WEB_COUNT=2 bash hw-01/create.sh
```

## Проверить стенд

```bash
bash hw-01/check.sh; echo $?
```

Три проверки:

1. балансировщик отвечает кодом 200;
2. ответили все веб-серверы;
3. сервер приложения доступен с `web-1` по внутреннему адресу.

Код возврата 0 — всё в порядке, 1 — хотя бы одна проверка не прошла.

## Если check.sh вернул 1

- **«балансировщик не найден»** — стенд не поднят, запустите `create.sh`.
- **«ответили машины (N из M)»** — посмотрите состояние целевой группы:

  ```bash
  TG_ID=$(yc load-balancer target-group get khikmatov-02-tg --format json | jq -r .id)
  yc load-balancer network-load-balancer target-states --name khikmatov-02-lb --target-group-id "$TG_ID"
  ```

  Машина в `UNHEALTHY` — зайдите на неё и проверьте `systemctl status nginx`. Прерываемую машину облако могло остановить: `yc compute instance start <имя>`.
- **«сервер приложения недоступен»** — на `khikmatov-02-app` не отработал cloud-init. Проверьте, что к подсети `khikmatov-02-subnet-a` привязана таблица маршрутизации с NAT-шлюзом, и пересоздайте машину.

## Удалить стенд

```bash
bash hw-01/destroy.sh
```

Удаляет все ресурсы с префиксом `khikmatov-02` и печатает, сколько осталось — должны быть нули.
